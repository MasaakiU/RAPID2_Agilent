# ピーク検出モデル（前段）の仕様 — v2

二段構成の前段（ピークトップの検出）の仕様。この文書の版は、`simulator.py` の `VERSION` と同じにする（シミュレータの出力を変えたら、両方を 1 つ上げる）。後段（当てはめによる範囲・面積の決定）は別に決める。学習は合成データだけで行い、実データ（`tools/peak_labeling` で正解を付けたもの）は評価だけに使う。

この文書の「未決」の印が、決める必要のある点。シミュレータの実装は `simulator.py`、例の生成と図は `make_examples.py`。

「採点しない」とは、そのサンプルは学習に使い、そのピークも信号には入れたまま、その位置の正解だけを損失の計算から外すこと。モデルがそこを「ピーク」と言っても「ピークでない」と言っても、罰も褒美も与えない。評価でも、そこへの予測は正解にも誤検出にも数えず、見落としにも数えない。

## 1. 役割

- 入力：1 本の 1 次元の信号（XIC、将来はスペクトルなども）。横軸の単位には依存しない。
- 出力：
  - 頂点の位置と confidence（ヒートマップ型なら、その極大）
  - 頂点ごとの、おおまかな左右の幅と裾の長さ（後段の当てはめの初期値）
  - 位置ごとの埋め込み（将来の用途のため。学習の対象にはしない）
- 前段は取りこぼさないこと（検出率）を重視する。裾の偽の頂点などは、後段の当てはめで落とす。

## 2. ピークの定義

信号は次のように作られるものとする。

```
y(t) = b(t) + Σ_k a_k · s_k(t) + ε(t)  （＋アーティファクト）
```

- `b(t)`：ベースライン。
- `s_k(t)`：k 番目の成分の形（最大値 1）。`a_k` は高さ。
- `ε(t)`：ノイズ。

**成分 k を「ピーク」とするのは、次をすべて満たすとき**。

1. **形**：単峰。サチュレーションの場合は、平らな頭を持つものも含める。
2. **幅**：半値幅（FWHM）が 2 点以上、300 点以下（`W_min = 2`、`W_max = 300`）。
   - 1 点だけのものはスパイクで、ピークではない。FWHM 2 点（半値より上に点が 2 つ）は、点の粗いデータのピークとして扱う。
3. **ベースラインとの区別**：周りに何があるかによらず、幅だけで決める。FWHM が `W_max` 以下の単峰の山は、太いピークに細いピークが乗っていても、それぞれピーク。ベースラインは、一定の値、ドリフト、段差と、`W_max` より太いうねりだけ。
   - 「ピークかどうかは、それ自体で決まる」とする。報告するかどうかは、後段や利用者が決める。
4. **有意さ**：高さ `a_k` と、頂点の周りのノイズの標準偏差 `σ_local` との比 `SNR_k = a_k / σ_local` で決める。`σ_local` は、実際に乗せたノイズの、頂点から `max(FWHM, 5)` 点以内のロバストな標準偏差。
   - `SNR_k ≥ 5` なら正例（ピーク）。（決定）
   - `SNR_k ≤ 2` なら、信号には入るが正例にはしない（非ピーク）。（決定）
   - その間は採点しない。
   - サチュレーションしたものは、S/N によらず正例とし、別に「サチュレーション」の印を付ける。（決定）

**頂点の位置**は、その成分自身の最大の位置とする（足し合わせた信号の最大ではない）。平らな頭の場合は、平らな部分の中央とする。

**近すぎる2つのピーク**は、分離度 `Rs = |t1 − t2| / (2 (σ1 + σ2))` で決める（σ は各成分の、ガウスに換算した幅）。

- `Rs ≥ 0.5` なら、2つの頂点を付ける。
- `Rs < 0.25` なら、1つのピークとみなし、足し合わせた信号の最大に頂点を1つ付ける。
- その間は、**小さい方だけ**を採点しない。大きい方は、1つに見えても2つに見えても確かにあるので、自分の判定のまま残す。小さい方が `SNR ≤ 2`（ノイズに埋もれて見えない）なら、組とはみなさない。
- 境目の値は決定。実データの正解付けの感覚に合うかは、開発用の実データで確かめる。
- ただし、この規則は **FWHM が 3 倍以内の組**だけに使う。幅がかけ離れていれば（細いピークが太いピークに乗っている）、まとめずに両方を付ける。太い方の頂点が細い方の真下（細い方の FWHM 以内）に隠れているときは、太い方の頂点の位置が見えないので、太い方だけ採点しない。

## 3. シミュレータ

### 3.1 形（成分ごとに、次から選ぶ）

| 形 | パラメータ |
|---|---|
| ガウス | σ |
| EMG（指数で裾を引くガウス） | σ、τ/σ = 0〜5 |
| 二重ガウス（左右で幅が違う） | σ_左、σ_右 |
| 裾の重い形（ローレンツ、Voigt 風） | 幅、混ぜ具合 |
| 任意の単峰 | 立ち上がりと減衰を、それぞれ乱数の単調な曲線で作る |
| サチュレーション | 上の形を、高さ `h_sat` で切る（平らな頭）。M 字形（頂点付近の欠け）も一部に入れる |

- 割合（成分ごと）：ガウス 15%、EMG 25%、二重ガウス 15%、裾の重い形 10%、任意の単峰 35%。
  - どの形も 10% 以上にして、それぞれを学べるだけ出す。
  - 一番多くを任意の単峰にして、決まった型（EMG など）を見つける学習に偏らないようにする。
  - EMG を次に多くするのは、実データで一番よくある崩れがテーリングだから。
- リーディングは、時間方向の反転で作る（50% の確率で信号全体を反転）。テーリングと同じだけ出る。
- サチュレーションは、強いピーク（S/N 100 以上）のあるサンプルの 10% で、一番強いピークに起こす。半分は M 字形にする。
- 割合は、実データ・開発用の失敗を見て見直す（足りない形が見つかったら足す）。

### 3.1.1 幅

- サンプルごとに「そのサンプルの幅」を、対数一様に 2.5〜200 点から選ぶ。
- 各成分の幅は、それを中心にばらつかせる（対数の標準偏差 0.3、つまり ±35% 程度）。実際のクロマトグラムで、1 本の中のピークの幅がだいたい揃っているのに合わせる。
- 成分の 10% は、幅の範囲（2〜300 点）全体から選ぶ（外れ値）。太いピークに細いピークが乗る例も、ここから出る。

### 3.1.2 点の粗いデータ

- サンプルの 30% は、2〜8 倍粗い格子で作ってから、線形補間で細かい間隔に戻す。粗い格子での幅は FWHM 2〜8 点（ピーク 1 つに数点しかない）。
- 推論で、点の粗い実データを細かい刻みに補間したときの見え方（頭が折れ線になり、本当の頂点が点と点の間に隠れる）を、そのまま学習させるため。
- 正解の頂点は、点と点の間でも成分の本当の位置とする。学習のヒートマップの広がりと評価の許容幅は、FWHM に比例させるので、点が粗いほど広くなる。

### 3.2 ピークの数と配置

- 1 サンプルあたりの成分数は、ポアソン分布。期待値は「ピークで埋め尽くすときの数」に、対数一様に 0.05〜1 を掛けたもの。まばらなサンプルが多く、密なサンプルは少ない（正例の数は、中央値 3、上位 10% で 28 以上）。
- 重なりが十分に出るように、一部は「かたまり」で置く。かたまりの中は、`Rs` が 0.1〜2 になるように間隔を取る。
- 成分を 1 つも置かないサンプル（ノイズとベースラインだけ）も、一定の割合で入れる。

### 3.3 高さ

- `SNR` で対数一様に、0.5〜10⁶ の範囲で振る。正例と、しきい値付近と、ピークでない小山が、どれも出るようにする。
- Q-TOF では、ノイズの床が数十〜数百カウント、ピークが 10⁶〜10⁷ になるので、1 本の中の強さの比は 10⁵〜10⁶ になりうる。強度の絶対値は、入力をトレースごとに正規化するので問題にならない。効くのは S/N と、1 本の中の比。

### 3.4 ベースライン

- 一定値（ノイズの 0.1〜10⁴ 倍）、直線のドリフト、ゆっくりしたうねり（太いガウスの和）、なだらかな段差（シグモイド）。
- うねりの FWHM は `W_max` の 1.2〜4 倍、段差の幅もそれ以上にする（2 の条件 3）。

### 3.5 ノイズ

- 白色ガウス、色付き（1/f）、強度に比例するもの（ポアソン的なもの、乗算的なもの）を、組み合わせて入れる。
- スパイク（1 点だけの外れ値）。
- 0 で切れる（負にならない）。centroid データのように、0 が多い信号も一部に入れる。
- 欠測（測っていない点）。前後の点から線形補間した値にし、入力に「欠測の印」のチャンネルを付ける。実データでも、欠測のスキャンを抜いて補間してから入れるので、それにそろえる。

### 3.6 サンプリング

- 長さ：512〜4096 点。
- 間隔に、わずかなゆらぎを入れる。

### 3.7 出力（正解）

1 サンプルごとに、次を出す。

- 信号（ノイズあり）と、そのノイズなし版（ノイズ除去の補助タスクと、ノイズへの不変性のため）
- 同じノイズなし版に、別のノイズを乗せたもう1本（不変性のため、一部のサンプルだけ）
- 頂点の位置と、正例・採点しない、の区別
- 頂点ごとの、高さ・左右の幅・裾の長さ・形の種類・サチュレーションかどうか
- 欠測の印

## 4. 入力の扱い

- 学習：長さも幅も点数で振るので、横軸の単位はない。
- 推論：実データは、ピークが 2 の幅の範囲の真ん中あたりに来る刻みに補間してから入れる。刻みは、データの種類ごとに決める推論時の換算で、学習の範囲は手元のデータに縛られない。
  - LC-MS の XIC は 0.5 秒ごと。手元のデータ（スキャン間隔 1 秒、FWHM 4〜20 秒、まれに 40 秒）では、FWHM が 8〜40 点になり、学習の範囲 2〜300 点（対数で真ん中は約 25 点）のほぼ真ん中に来る。
  - 点の粗いデータ（スキャン間隔が長い、DDA で MS1 がまばら、など）も同じ刻みに補間する。補間した見え方は 3.1.2 で学習させる。
- 入力は XIC 全体（トレース 1 本）。学習の長さ 512〜4096 点は、0.5 秒ごとなら 4〜34 分。それより長い測定は、重ねた区切りで入れ、結果をまとめる。正規化は、入れる単位（トレースか区切り）ごとに行う。
- 受容野：一番太いピーク（300 点）と、その周りの文脈を見られるよう、900 点以上にする。
- チャンネル（3 本）：
  - 線形：低い分位点を引き、ロバストな最大値で割ったもの。強いピークの形・肩・谷を見るため。
  - log：低い分位点を引き、ノイズの大きさで割ったものの log1p（S/N の単位での log）。強いピークの隣の小さなピークを見るため。
  - 欠測の印。
  - log だけ（線形なし）との比較は、実験で確かめる。

## 5. 学習

- 損失：
  - 頂点のヒートマップ：focal loss（採点しない部分は除く）
  - 頂点の細かいずれ：L1
  - 幅（log）：L1
  - 補助：ノイズなし版の再構成、ノイズの違う2本のヒートマップの一致
- 易しい順の学習：SNR の高いもの・重なりの少ないものから始め、だんだん広げる。
- 候補（K、A、A′、B、C）は、同じシミュレータで学習する。

## 6. 評価

### 6.1 データ

| データ | 用途 |
|---|---|
| 合成の試験用 | 学習と同じ分布での成績 |
| 合成の分布外 | 学習から外した形（例：リーディングを外して学習し、リーディングで評価）。概念を学んだかを見る |
| 実データ・開発用 | 失敗を眺めて、シミュレータに足りないものを見つける |
| 実データ・最終評価用 | シミュレータの設計に使わず、最後に一度だけ測る |

### 6.2 指標

- 頂点の対応付け：正解の頂点から `max(2 点, 0.5 × FWHM)` 以内の、まだ対応していない予測を、confidence の高い順に対応させる。
- 適合率・再現率・F1：confidence のしきい値ごとに出す（PR 曲線）。しきい値は実データ・開発用で決める。
- 内訳：孤立・重なり・テーリング・リーディング・サチュレーション・低 S/N・ピークなしの区間ごとに集計する。
- 位置の誤差：対応した頂点の、点数での差。
- 比べる基準：簡易版（scipy）、centWave、今の Kensert、peakonly。
