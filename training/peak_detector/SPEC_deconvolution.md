# ピークの分離（後段）の仕様 — 案

二段構成の後段の仕様。前段（[SPEC.md](SPEC.md)、ピークトップの検出）が出した頂点の候補と信号から、ピークごとの形と面積、ベースライン、ノイズの大きさを出す。重なったピークを分けること（デコンボリューション）が目的。学習は前段と同じシミュレータの合成データだけで行い、実データは評価だけに使う。

この文書の「未決」の印が、決める必要のある点。

## 1. 役割

信号を、前段の SPEC 2 と同じく次のように見る。

```
y(t) = b(t) + Σ_k a_k · s_k(t) + o(t) + ε(t)
```

- `b(t)`：ベースライン。
- `s_k(t)`：候補 k のピークの形（単峰、最大値 1）。`a_k` は高さ。面積は `a_k ∫ s_k dt`。
- `o(t)`：どの候補にも当たらない成分の和（前段が見落としたピーク、S/N 2 以下の小山、細いピークの真下に頂点が隠れた太いピークなど）。
- `ε(t)`：ノイズ。点ごとの標準偏差 `σ(t)`。

二つに分けて求める。

1. **形（DL）**：信号と候補から、候補ごとの形 `s_k`、本物らしさ（0〜1）、高さの見積もり `â_k` と、`b`、`o`、`σ` を出す。形は決まった式（EMG など）に縛らない。
2. **量（最小二乗）**：本物らしさがしきい値以上の候補について、高さ `a_k` を、重み `1/σ(t)²`、`a_k ≥ 0` の最小二乗で決める。DL の見積もり `â_k` へ引き寄せる項を足し、形どうしが似すぎて不安定なところを抑える。
   - 量を決めるのは DL ではなく、実際のデータへの当てはまりにする。DL は形にだけ責任を持つ。
   - 最小二乗の共分散から、面積の不確かさを出す。重なりが強いほど形どうしが似て、不確かさが大きく出る。
   - 残差 `y − b − o − Σ a_k s_k` が `σ` に比べて大きいところは、失敗の印として出す。

入力：

- 信号：前段と同じ刻みとチャンネル（線形、log、欠測の印。SPEC 4）。
- 候補の一覧：位置、確信度、左右の幅（前段の出力を、低いしきい値で切ったもの）。前段は取りこぼさないことを重視するので、余計な候補（重複、裾や肩の上、ノイズの上）が正しい候補より多く混ざる（v4 の実データで、しきい値 0.1 なら正解 152 個に対して 145〜213 個）。それを本物らしさで落とすのも後段の役目。
- 前段の中間の特徴は使わない。前段を学習し直しても、後段を学習し直さずに済むように、前段とは候補の一覧だけでつなぐ。
- 前段のヒートマップを入力のチャンネルに足すか。（未決）

出力：

- ピークごと：形、高さ、面積とその不確かさ、頂点、範囲（形が 5% まで下がるところ）、本物らしさ。
- トレースごと：ベースライン、`o`、ノイズの大きさ、残差。

## 2. 正解の定義

- **ピーク**：前段の正解（SPEC 2）の、正例と「採点しない」もの。どちらも信号の中に確かにある成分なので、形の正解を持つ。近すぎて 1 つにまとめた成分（`Rs < 0.25`）は、その和を 1 つのピークの形とする。
- **形の正解**：そのピークのノイズなしの信号（成分の高さ×形、まとめたものはその和）を、最大値 1 にしたもの。
  - サチュレーションしたピークは、測ったままの（頭を切られた、M 字形も含む）形とし、面積もその形の面積とする。（決定）切られる前の量は求めない。外挿した面積は不正確になりやすいため。
  - 切られた分は、その点で一番大きい成分（ピークと `o` のうち）から順に引く。サチュレーションした成分が切られた分をまかない、隣のピークは形を保つ（大きさに比例して引くと、隣の太いピークの形に、切られたところで折れ目ができた）。成分の和より多く切られたところ（ベースラインが天井より上）だけ、残りをベースラインから引く。
  - 0 の区間（SPEC 3.6）の中は、形も 0。
- **ベースラインの正解**：シミュレータのベースライン（一定値、ドリフト、うねり、段差、急な段差）に、0 の区間から戻るときの飛び出しを足したもの。0 の区間の中は 0。ノイズなし版を 0 で切ったサンプル（SPEC 3.7）で持ち上げた分は、ベースラインのもの（0 より下になるのはベースラインだけなので）。
- **`o` の正解**：候補に当たらなかったピークと、S/N 2 以下の小山（非ピーク）の和。
- **ノイズの大きさの正解**：点ごとに乗せたノイズの標準偏差（白色、色付き、ショット、乗算的なものの分散の和から）。スパイク（1 点だけの外れ値）は含めず、外れ値として扱う。どう扱うか（重みを下げる、残差から見つける）は（未決）。
- **候補と正解の対応**：前段の評価（`decode.assign`）と同じ規則で、確信度の高い候補から、`max(2 点, 0.5 × FWHM)` 以内の、まだ対応していない一番近いピークに対応させる。
  - 正例に対応した候補：本物らしさ 1、形の正解はそのピーク。
  - 「採点しない」ピークに対応した候補：形の正解はそのピーク。本物らしさは採点しない。
  - 対応の無い候補（重複、裾、ノイズの上）：本物らしさ 0、形の正解なし（高さ 0）。
- `Rs` が 0.25〜0.5 の組の小さい方（前段で採点しないもの）の面積を、成績に入れるか。分け方がもともと決まりにくいところなので、別に集計する案。（未決）

## 3. シミュレータに足すもの（v6 で実装）

- サンプル（`simulator.Sample`）に、`baseline`、`others`、`sigma`（点ごとのノイズの標準偏差）。ピーク（`simulator.Peak`）ごとに、`profile`（そのピーク自身のノイズなしの信号。最大値 1 にする前の、信号の単位）と、それが始まる点 `start`。
  - いつも `clean = baseline + others + Σ profile`（テストで確かめる）。
  - `profile` は、自分の最大値の 100 万分の 1 を超えるところだけを持ち、その外の裾は `others` に入れる。
  - `others` は、一覧に無い成分（頂点がサンプルの外のもの、0 の区間の奥に頂点があって除いたもの、学習の窓の外のもの）と、遠い裾。後段の学習の `o` は、これに、候補に当たらなかったピーク（S/N 2 以下の小山を含む）の `profile` を足したもの。
  - `sigma` は、白色・色付き・ショット・乗算的なノイズの分散の和の平方根（サチュレーションしたところは 0.1 倍、0 の区間は 0）。スパイクは含めない。点の粗いデータでは、格子の上の値を線形補間する（間の点のノイズは両隣の点のノイズの混ざりで、本当はそれより小さく、隣どうしで相関がある。最小二乗の不確かさを、実際の誤差で確かめる必要がある）。
- 点の粗いデータ（SPEC 3.1.2）、反転、0 の区間、学習の窓の切り出し（`data.cut`）のそれぞれで、信号と同じ変換をかける。
- 今の信号と前段の正解ラベルは変えない。v5 と v6 のコードで 400 サンプルを作り、信号、ノイズなし版、欠測、正解ラベル、学習の正解、乱数の状態が、ビット単位で同じことを確かめた。前段の学習データは同じで、v5 と v6 の前段の結果はそのまま比べられる。サンプルを作る時間も変わらない（1 つ 4.5 ms）。

## 4. モデル

- 前段とは別の、自分の encoder を持つ（前段と同じく、畳み込みの U-Net と、畳み込み＋Transformer の両方を候補にする）。
- 候補ごとに 1 つの枠（クエリ）を作る：位置、確信度、幅を埋め込み、信号の特徴に注意を向けて、その候補の形、本物らしさ、高さの見積もりを出す。候補どうしも互いを見て、重複を落とせるようにする。
- 形は、頂点までは対数の傾きが 0 以上、頂点からは 0 以下になるように出力し、それを積み上げて作る。どんな単峰の形でも表せ、決まった式には縛られない（SPEC 2 の「単峰」に合わせる）。
- トレース全体に、`b`、`o`、`log σ` を出す。
- 学習では、最小二乗を中に入れる（微分できる）。損失は、形の誤差、本物らしさ、高さの見積もり、ベースライン、`o`、ノイズの大きさ（正規分布の尤度）と、最小二乗で出た面積の相対誤差。DL は「最小二乗にかけたときに正しい面積が出る形」を学ぶ。
- 学習の候補：
  - はじめは、正解の頂点に、ずれ（FWHM の 0〜0.3 倍）、重複（頂上や裾の上の余分な候補）、抜け、ノイズの上の偽の候補を、人工的に足したもの。前段から切り離して作れる。
  - 後で、固定した前段を合成データにかけた、実際の候補を混ぜる。割合は（未決）。
- 最小二乗の引き寄せの強さ、本物らしさのしきい値は、合成データで決める。（未決）

### 4.1 実装（`deconvolve_models.py`、`deconvolve_losses.py`、`deconvolve_data.py`、`train_deconvolution.py`）

- 単位は、前段の入力の線形チャンネルの単位。窓のベースライン（5 パーセンタイル）を引き、最大値で割ったもの。
- encoder：前段の `transformer`（畳み込みと、長さ 1/4 の Transformer）か `unet` と同じ作り。点ごとの特徴と、注意を向けるトークンを出す。
- 候補の枠：
  - 頂点での特徴、幅と確信度、位置の埋め込み（サイン波）から作る。
  - 3 層の Transformer decoder で、枠どうし（重複を見分けるため）と、トークンに注意を向ける。
  - 枠から、本物らしさと高さの見積もりを出す。高さは、頂点での信号の値からのずれとして出す。
- 形：
  - 候補ごとに、自分の幅の ±4 倍を 128 点の格子にとる（左右で別の幅）。ピークの太さによらず、同じ見え方になる。
  - 格子の上で、次のものを畳み込みにかけ、枠の情報で調整（FiLM）する：特徴、入力のチャンネル、ほかの候補の位置（本物らしさで重みを付けたもの）、格子の位置、その側の幅。
  - 出力は、頂点の位置（格子の上の重みの平均）と、上りと下りの対数の傾き（exp で 0 以上）。頂点から外へ足し上げて、対数の形にする。
  - 左右の裾の深さは、それぞれ自由。格子の外は、端の傾きのまま伸ばす。
  - はじめに作った「左からの和と右からの和の小さい方」では、頂点の条件から左右の端の深さが同じになってしまい、テーリングした形が表せなかった（1 バッチへの過学習でも、形の誤差が 0.23 から下がらなかった。直して 0.07）。
- 窓ごとの出力：ベースライン、その他、log σ。σ は、窓のノイズの見積もり（`features.Scaling`）からのずれとして出す。出力の層は float32 で計算する（bf16 では、0 から遠いベースラインの細かい差が表せない）。
- 最小二乗（学習の中も、使うときも）：
  - 高さ `a ≥ 0` に加えて、候補のまとまりごとに、ベースラインの補正（範囲の中で 1 になる定数と、真ん中で 0 になる傾きの 2 つ。符号は自由）を一緒に解く。
    - まとまりは、範囲（幅の 4 倍）が重なる候補の集まり（`deconvolve.clusters`、`deconvolve.corrections`）。
    - DL のベースラインとその他は、段差や曲がりのような大まかな形を持ち、ピークのそばのずれ（オフセットと傾き）は、データへの当てはめで直す。まとまりの両端を結ぶ、ベースラインの引き方を、最小二乗の中で行うもの。
    - 補正なしでは、小さなモデルで、ベースラインとその他のずれがノイズの 100 倍ほど残った。S/N の高い窓の小さなピークでは、ピークの高さと同じくらいのずれで、面積が 0 になった。補正を入れて、1 バッチへの過学習で、ほとんどのピークの面積の誤差が 10% 以内になった。
  - 引き寄せ：`strength × (a_k − â_k)² ×（データが a_k だけについて持つ情報、Σ w s_k²）`。既定の `strength` は 0.01。孤立したピークではデータの 1% の重みしか持たない。形がよく似た組では、決まらない方向だけを抑える。
  - 重みは、出した σ から `1/σ²`。σ には勾配を流さない。測っていない点と、信号がちょうど 0 の点（測っていない区間か、0 で切られたところ）は、重み 0。
  - 学習の中では、正解に対応した候補だけを入れる（候補の採否は、本物らしさの損失で別に学ぶ）。torch で、0 より下になったものを外して解き直す（4 回まで。Lawson–Hanson の近似）。解の線形方程式を通して、形・ベースライン・その他に勾配が流れる。
  - 使うときは、本物らしさが `real` 以上の候補を入れ、`scipy` の非負の最小二乗で解く（補正は、射影で消してから高さを解く）。共分散から、面積の不確かさを出す。
- 0 が 4 点以上続くところ（測っていない区間）では、形を 0 にする（`deconvolve.present`）。
- 損失（`deconvolve_losses.py`）：
  - 形：L1 を正解の和で割ったもの
  - 本物らしさ：交差エントロピー
  - 高さ：log の L1
  - ベースラインとその他：`log(1 + |誤差| / σ)`。窓の最大値の単位では、S/N の高い窓のノイズの何十倍ものずれが、小さな損失にしかならなかったため。
  - ノイズ：log の L1
  - 面積：最小二乗で出した面積の `log(1 + |相対誤差|)`
  - 重みは当て推量で、学習の結果を見て直す。
- 安定のため：
  - 形を最大値 1 にするのは、log の上で最大値を引いてから exp をとる（最大値が 1e-30 ほどの形で、割り算の勾配があふれ得た）。
  - 重みに使う σ は、窓のノイズの e⁻⁵ 倍より下にしない（1 点に重みが集まると、解が不安定になる）。
  - 勾配が有限でないステップは飛ばし、その数を記録する（`skipped`）。CPU の小さなモデルの試し（3000 ステップ）で、2000 ステップを過ぎたところで一度すべて NaN になったため。同じデータでたどり直しても再現しなかった。
- 検証（`train_deconvolution.check`）は、使うときと同じ道筋で、5 の成績と本物らしさの AP を出す。`best.pt` は、面積の `log(1 + |相対誤差|)` の平均（見落としは 1）と、余計な候補が持った面積の割合の和が、一番小さいもの。

## 5. 評価

- ピークごと（候補に対応した正解）：
  - 面積の相対誤差（中央値、90 パーセンタイル）
  - 形の誤差（最大値 1 にした形の L1）
  - 範囲（5% まで下がるところ）の誤差
  - 不確かさの当たり具合（誤差 ÷ 出した不確かさ の分布が、標準正規に近いか）
- 候補の採否：本物らしさでの PR（余計な候補をどれだけ落とし、正しい候補をどれだけ残すか）。
- 内訳：孤立、重なり（隣との `Rs`：0.25〜0.5、0.5〜1、1〜1.5、1.5 以上）、隣との高さの比、形、S/N、サチュレーション、0 の区間や急な段差のそば。
- 比べる基準：
  - 正解の形での最小二乗：形が完璧なときに、ノイズだけで避けられない誤差（下限）。
  - EMG の和の当てはめ（初期値は候補）：古典的なやり方。
  - 今のアプリのやり方（範囲の台形の積分と、範囲内の最小値の平らなベースライン、`services/quantification.py`）。
- 基準の成績（v6、同じ 300 窓、1731 ピーク。`evaluate_deconvolution.py`）。面積の相対誤差の中央値 / 90 パーセンタイル（アプリは、中央値の偏り）：

  | | 全体 | 孤立 | `Rs` 0.25〜0.5 | `Rs` 0.5〜1 | 隣が 10 倍以上 | S/N 20 未満 | 誤差 ÷ 出した σ の広がり |
  |---|---|---|---|---|---|---|---|
  | 正解の形での最小二乗 | 0.3% / 8% | 0.4% / 8% | 0.2% / 8% | 0.3% / 8% | 1.7% / 16% | 5% / 28% | 1.3（点の粗いもの 1.8） |
  | EMG の当てはめ（正解の候補） | 19% / 5500% | 6% / 1150% | 80% / 25000% | 30% / 10600% | +1000%（大きく出る） | +250% | 430 |
  | EMG の当てはめ（誤りを足した候補） | 35% / 3800% | 14% / 930% | 84% / 13000% | 42% / 4600% | +760% | +140% | 515 |
  | アプリのやり方（正解の候補） | −60% | −48% | −100% | −96% | −100% | −100% | — |

  - 形が正しければ、重なっていても面積はほぼノイズの分の誤差で決まる（`Rs` によらない）。難しさは形を知ることにあり、そこを DL に任せる理由になる。
  - 式の形での当てはめは、孤立した強いピーク（S/N 100 以上で中央値 7%）にしか効かない。大きなピークの隣の小さなピークは、大きい方の裾を取り込んで面積が 10 倍に出る（大きい方の形が EMG に合わないため）。出した σ は誤差の 1/400 ほどで、形の誤りを表さない。
  - 誤りを足した候補では、EMG は余計な候補に全体の面積の 13% を持たせた。候補の採否は欠かせない。
  - アプリのやり方は分離をしない：重なったものや隣が大きいものの面積はほぼ 0、孤立したものでも、範囲（プロミネンスの 80%）と範囲の最小値の平らなベースラインで半分ほどになる。
  - 正解の形でも、最小二乗の σ は誤差を 3 割ほど小さく見積もる（色付きのノイズ、点の粗いデータの補間で、ノイズに隣どうしの相関があるため）。後段の σ は、合成データの誤差で補正する。
  - 時間：1 窓に、正解の形の最小二乗とアプリは 0.02 秒、EMG は 3〜20 秒（同時に 6 本回して）。
- 実データ（面積の正解は無い）：
  - 合成したピークを実データのトレースに足す（ノイズとベースラインは本物、ピークの正解は分かっている）。
  - 同じ脂質の付加イオンどうし（[M+H]+、[M+Na]+、[M+K]+ など）は溶出の形が同じはずなので、分けた形がそろうか。
  - できれば実験：2 つの標準品を別々に測り、溶出が重なるように混ぜても測る。

## 6. 決まったこと・残っていること

| 項目 | 状態 |
